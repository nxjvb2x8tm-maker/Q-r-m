# Laf et — Flutter (iOS + Android)

Премиальное приложение для изучения **крымскотатарского языка**. Один код на
Dart разворачивается и на iOS, и на Android без переписывания под платформу.

## Четыре главных экрана + панель управления

Плавающая нижняя панель (`lib/widgets/nav_bar.dart`) переключает между ними:

| # | Экран | Файл | Что показывает |
|---|-------|------|----------------|
| 1 | **Yol · Путь** | `screens/journey_screen.dart` | Волнистый путь как в Duolingo. Каждый модуль = 8 кружочков-уроков: **3 словаря → 2 грамматики → 2 задания → 1 чтение**. Между большими модулями («Bölük») — линия-разделитель и цветной баннер. Тап по текущему кружку открывает урок. |
| 2 | **Ösüş · Прогресс** | `screens/progress_screen.dart` | Кольцо общего прогресса курса, серия/XP/точность, разбивка по типам уроков (словарь/грамматика/задания/чтение), график активности за неделю, достижения. |
| 3 | **Modüller · Модули** | `screens/modules_screen.dart` | Длинный список всех модулей курса A1 с фильтрами, прогрессом и быстрым возвратом к пройденному материалу (`module_detail.dart` — словарь модуля). |
| 4 | **Profil · Профиль** | `screens/profile_screen.dart` | Аватар, имя (редактируется), уровень, статистика, переключатель тёмной/светлой темы, уведомления, цель в день, виджет, помощь. |

## Дизайн-система

`lib/theme/app_theme.dart` — токены `DARK` / `LIGHT`, перенесённые из прототипа
`lafet.html`: акцент `#6C5CE7`, шрифт **Nunito** (через `google_fonts`), мягкие
«дорогие» тени, стеклянная (blur) навигация, градиентные карточки, кольцевые и
линейные индикаторы прогресса, анимации нажатий и появления экранов.

## Данные курса

- `lib/data/course.dart` — структура пути: 5 секций × 2 модуля × 8 уроков.
- `lib/data/catalog.dart` — полный каталог модулей (перенос `MODS` из прототипа).
- `lib/data/vocabulary.dart` — словари (перенос `WORDS…` из прототипа).

## Запуск

```bash
# 1. Сгенерировать платформенные папки (android/, ios/, ...) при первом запуске:
flutter create . --project-name laf_et --platforms=android,ios

# 2. Зависимости и запуск:
flutter pub get
flutter run
```

Точка входа — `lib/main.dart`. Минимальная версия SDK — Dart 3.3 / Flutter 3.19+.
